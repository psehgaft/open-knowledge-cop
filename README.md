## About

`open-knowledge-cop` is a placeholder for a project around open knowledge:
shared, reusable knowledge resources, maintained in the open and governed as
a community effort. The name suggests a "cop" in the sense of a community of
practice — people curating, reviewing, and keeping shared knowledge usable —
but the scope, tooling, and governance model are still to be defined.

## Current status

- Repository created on 2026-08-12.

- The only file so far is this README.

## Intended direction

These are goals for the project, not shipped features:

- Define what "open knowledge" means for this repository: what kind of
  resources it will host, and under which open license.
- Set up a simple contribution workflow so that additions are reviewed
  before they are published.
- Publish a first, small set of curated resources as a proof of concept.
- Document how the collection is maintained over time: review cadence,
  versioning, and archival of outdated material.
